# Glossary

Short definitions used by the lab. Links favor primary papers, Distill, Scholarpedia and standards.

<div class="glossary-grid">
<div class="glossary-term" id="carrier"><h3>Carrier</h3><p>The finite state used to represent source information. Experiment 01 uses one binary value per address.</p><div class="links"><a href="{{ '/carrier/' | relative_url }}">Experiment 01</a></div></div>
<div class="glossary-term" id="computational-pixel"><h3>Computational pixel</h3><p>A spatial address plus finite carrier/computational state plus an interpretation. The internal object is not restricted to visible RGB.</p><div class="links"><a href="{{ '/learn/' | relative_url }}">Start Here</a></div></div>
<div class="glossary-term" id="source-information"><h3>Source information</h3><p>The independent information supplied to an experiment before derived representations, model state or side information are added.</p><div class="links"><a href="{{ '/research/00-research-thesis/' | relative_url }}">Thesis</a></div></div>
<div class="glossary-term" id="projection"><h3>Projection / visualization</h3><p>A lower-dimensional human-visible view of a richer internal state. A color projection is not the full storage object.</p><div class="links"><a href="https://en.wikipedia.org/wiki/Dimensionality_reduction">Background</a></div></div>
<div class="glossary-term" id="tensor"><h3>Tensor pixel</h3><p>A pixel whose internal state has explicit array axes, such as a 4×4 latent matrix. A fair test compares it with a flat state under declared resource matching.</p><div class="links"><a href="https://en.wikipedia.org/wiki/Tensor">Tensor</a><a href="{{ '/experiment/primitive-benchmark/' | relative_url }}">Benchmark</a></div></div>
<div class="glossary-term" id="micro-transformer"><h3>Micro-transformer pixel</h3><p>Several latent tokens live inside one outer address and self-attention mixes them. This differs from a field Transformer, where attention operates between outer addresses.</p><div class="links"><a href="https://arxiv.org/abs/2103.00112">Transformer in Transformer</a><a href="{{ '/experiment/interpretation/' | relative_url }}">Mechanics</a></div></div>
<div class="glossary-term" id="nca"><h3>Neural Cellular Automaton (NCA)</h3><p>A differentiable cellular automaton with vector-valued cells and a learned local update rule. It is a major baseline for learned multidimensional local cells.</p><div class="links"><a href="https://distill.pub/2020/growing-ca/">Growing NCA</a><a href="https://distill.pub/2020/selforg/mnist/">Self-classifying NCA</a></div></div>
<div class="glossary-term" id="recurrence"><h3>Recurrence</h3><p>Reusing state through time so the next state depends on a previous state. It is one experimental axis, not the definition of MPF.</p><div class="links"><a href="https://www.scholarpedia.org/article/Recurrent_neural_networks">Scholarpedia</a></div></div>
<div class="glossary-term" id="attention"><h3>Attention</h3><p>A weighted interaction mechanism. In this project it may operate inside a pixel, between pixels, between regions or between fields.</p><div class="links"><a href="https://arxiv.org/abs/1706.03762">Transformer paper</a></div></div>
<div class="glossary-term" id="message-passing"><h3>Message passing</h3><p>Nodes aggregate information from connected neighbors and update their state. A regular pixel grid is one graph topology among many.</p><div class="links"><a href="https://distill.pub/2021/gnn-intro/">Distill: GNNs</a></div></div>
<div class="glossary-term" id="hopfield"><h3>Hopfield memory</h3><p>A recurrent content-addressable memory with attractor dynamics. The atlas uses the classical fully connected bipolar model as a transparent binary-memory baseline.</p><div class="links"><a href="https://authors.library.caltech.edu/records/w41x7-8bn13">Hopfield 1982</a><a href="{{ '/experiment/memory/' | relative_url }}">Experiment 03</a></div></div>
<div class="glossary-term" id="hamming"><h3>Hamming(7,4)</h3><p>A block error-correcting code that maps four data bits to seven transmitted bits and corrects any single-bit error in a codeword. Multiple errors can be miscorrected.</p><div class="links"><a href="https://en.wikipedia.org/wiki/Hamming(7,4)">Background</a><a href="{{ '/experiment/reliability/' | relative_url }}">Experiment 02</a></div></div>
<div class="glossary-term" id="hdc"><h3>Hyperdimensional Computing / VSA</h3><p>High-dimensional distributed representations with algebraic operations such as binding and bundling. Dimensional expansion is derived state, not free source information.</p><div class="links"><a href="https://arxiv.org/abs/2111.06077">Survey</a><a href="{{ '/experiment/hypervector/' | relative_url }}">Experiment 05</a></div></div>
<div class="glossary-term" id="hyperbolic"><h3>Hyperbolic geometry</h3><p>A negatively curved geometry useful to test on genuinely hierarchical structures. It is not an extra dimension and is separate from HDC/high dimensionality.</p><div class="links"><a href="https://arxiv.org/abs/1705.08039">Poincaré embeddings</a></div></div>
<div class="glossary-term" id="vq"><h3>Vector quantization</h3><p>Representing a vector by a codebook index. Codebook and side-information cost must be counted in compression experiments.</p><div class="links"><a href="https://arxiv.org/abs/1711.00937">VQ-VAE</a></div></div>
<div class="glossary-term" id="rate-utility"><h3>Rate–utility</h3><p>Useful task performance obtained for a declared number of stored/transmitted bits. Related rate–distortion measurements use reconstruction distortion instead of task utility.</p><div class="links"><a href="https://en.wikipedia.org/wiki/Rate%E2%80%93distortion_theory">Rate–distortion</a></div></div>
<div class="glossary-term" id="recursive-field"><h3>Recursive field</h3><p>A field in which an address may contain another field and a common interface/operator is reused across levels. Pooling alone is not sufficient evidence of recursion.</p><div class="links"><a href="{{ '/research/03-concepts-to-explore/' | relative_url }}">Open questions</a></div></div>
<div class="glossary-term" id="semantic-album"><h3>Semantic Album</h3><p>A proposed higher-order system in which persistent fields become objects that can be retrieved, compared or allowed to interact.</p><div class="links"><a href="{{ '/research/03-concepts-to-explore/' | relative_url }}">Open questions</a></div></div>
<div class="glossary-term" id="ablation"><h3>Ablation</h3><p>A controlled intervention that removes or alters one mechanism to estimate its causal contribution.</p><div class="links"><a href="{{ '/research/02-experiment-protocol/' | relative_url }}">Method</a></div></div>
<div class="glossary-term" id="ood"><h3>OOD / out-of-distribution</h3><p>Evaluation on cases that systematically differ from training, such as longer distances, larger grids or deeper structures.</p><div class="links"><a href="{{ '/research/06-learning-and-training/' | relative_url }}">Learning</a></div></div>
</div>
