# Glossary

Definitions emphasize the operational meaning of each term and the measurement it implies.

<div class="glossary-grid">
<div class="glossary-term" id="carrier"><h3>Carrier</h3><p>The finite state that physically or computationally represents source information. A binary pixel carrier stores one bit at each address.</p><div class="links"><a href="{{ '/carrier/' | relative_url }}">Binary carrier</a></div></div>
<div class="glossary-term" id="computational-pixel"><h3>Computational pixel</h3><p>A spatial address plus finite carrier or computational state plus an interpretation. The internal object is not restricted to a visible RGB value.</p><div class="links"><a href="{{ '/learn/' | relative_url }}">Foundations</a></div></div>
<div class="glossary-term" id="source-information"><h3>Source information</h3><p>The independent information supplied before derived representations, hidden state, parameters, metadata, or side information are added.</p><div class="links"><a href="{{ '/research/00-research-thesis/' | relative_url }}">Research thesis</a></div></div>
<div class="glossary-term" id="projection"><h3>Projection / visualization</h3><p>A lower-dimensional view of richer internal state. Mapping selected latent values to color makes them visible without making the color image identical to the stored object.</p><div class="links"><a href="https://en.wikipedia.org/wiki/Dimensionality_reduction">Dimensionality reduction</a></div></div>
<div class="glossary-term" id="tensor"><h3>Tensor pixel</h3><p>A pixel whose internal state has explicit array axes, such as a 4×4 latent matrix. The tensor is meaningful only when operations preserve or exploit that factorization.</p><div class="links"><a href="https://en.wikipedia.org/wiki/Tensor">Tensor</a><a href="{{ '/experiment/primitive-benchmark/' | relative_url }}">Benchmark</a></div></div>
<div class="glossary-term" id="micro-transformer"><h3>Internal-token / micro-transformer pixel</h3><p>Several latent tokens occupy one outer address and self-attention mixes them. A field Transformer is different: its attention operates between outer addresses.</p><div class="links"><a href="https://arxiv.org/abs/2103.00112">Transformer in Transformer</a><a href="{{ '/experiment/interpretation/' | relative_url }}">Pixel primitives</a></div></div>
<div class="glossary-term" id="nca"><h3>Neural Cellular Automaton (NCA)</h3><p>A differentiable cellular automaton with vector-valued cells and a learned local update rule. NCA is a primary baseline for learned multidimensional local fields.</p><div class="links"><a href="https://distill.pub/2020/growing-ca/">Growing NCA</a><a href="https://distill.pub/2020/selforg/mnist/">Self-classifying NCA</a></div></div>
<div class="glossary-term" id="recurrence"><h3>Recurrence</h3><p>Reusing state through time so a new state depends on a previous state. Recurrence can propagate local information, preserve memory, or allocate iterative compute; it is not required by every computational-pixel architecture.</p><div class="links"><a href="https://www.scholarpedia.org/article/Recurrent_neural_networks">Scholarpedia</a></div></div>
<div class="glossary-term" id="attention"><h3>Attention</h3><p>A weighted interaction mechanism in which a query determines how strongly different keys and values contribute to an update. Attention can occur inside one pixel, between pixels, between regions, or between fields.</p><div class="links"><a href="https://arxiv.org/abs/1706.03762">Transformer paper</a></div></div>
<div class="glossary-term" id="message-passing"><h3>Message passing</h3><p>A graph computation in which nodes aggregate information from connected neighbors and update their state. A regular pixel grid is one possible connectivity graph.</p><div class="links"><a href="https://distill.pub/2021/gnn-intro/">Distill: GNNs</a></div></div>
<div class="glossary-term" id="hopfield"><h3>Hopfield memory</h3><p>A recurrent content-addressable memory with attractor dynamics. In the classical bipolar model, stored patterns determine a dense weight matrix and asynchronous updates move state toward fixed points.</p><div class="links"><a href="https://authors.library.caltech.edu/records/w41x7-8bn13">Hopfield 1982</a><a href="{{ '/experiment/memory/' | relative_url }}">Associative memory</a></div></div>
<div class="glossary-term" id="hamming"><h3>Hamming(7,4)</h3><p>A block error-correcting code that maps four source bits to seven transmitted bits and corrects any single-bit error within one codeword. Multiple errors in the same codeword can be miscorrected.</p><div class="links"><a href="https://en.wikipedia.org/wiki/Hamming(7,4)">Background</a><a href="{{ '/experiment/reliability/' | relative_url }}">Error correction</a></div></div>
<div class="glossary-term" id="hdc"><h3>Hyperdimensional Computing / VSA</h3><p>High-dimensional distributed representations with algebraic operations such as binding, bundling, permutation, and similarity retrieval. Dimensional expansion is derived state rather than new source information.</p><div class="links"><a href="https://arxiv.org/abs/2111.06077">Survey</a><a href="{{ '/experiment/hypervector/' | relative_url }}">Hypervector field</a></div></div>
<div class="glossary-term" id="hyperbolic"><h3>Hyperbolic geometry</h3><p>A negatively curved geometry that can represent branching hierarchies efficiently. Hyperbolic curvature is separate from the number of dimensions and from HDC.</p><div class="links"><a href="https://arxiv.org/abs/1705.08039">Poincaré embeddings</a></div></div>
<div class="glossary-term" id="vq"><h3>Vector quantization</h3><p>Replacing a continuous vector with the index of a codebook entry. Compression accounting must include indices, codebooks, metadata, and residual information required for reconstruction.</p><div class="links"><a href="https://arxiv.org/abs/1711.00937">VQ-VAE</a></div></div>
<div class="glossary-term" id="rate-utility"><h3>Rate–utility</h3><p>Useful task performance obtained for a declared number of stored or transmitted bits. Rate–distortion uses reconstruction distortion instead of downstream utility.</p><div class="links"><a href="https://en.wikipedia.org/wiki/Rate%E2%80%93distortion_theory">Rate–distortion</a></div></div>
<div class="glossary-term" id="recursive-field"><h3>Recursive field</h3><p>A field in which an address can contain another active field and a common interface or operator is reused across levels. Ordinary pooling does not by itself establish recursion.</p><div class="links"><a href="{{ '/research/03-concepts-to-explore/' | relative_url }}">Open mechanisms</a></div></div>
<div class="glossary-term" id="semantic-album"><h3>Semantic Album</h3><p>A higher-order memory in which persistent fields become addressable objects that can be retrieved, compared, updated, combined, or consolidated.</p><div class="links"><a href="{{ '/research/03-concepts-to-explore/' | relative_url }}">Persistent field memory</a></div></div>
<div class="glossary-term" id="ablation"><h3>Ablation</h3><p>A controlled intervention that removes or alters one mechanism while leaving the rest of the system as unchanged as possible, allowing its causal contribution to be estimated.</p><div class="links"><a href="{{ '/research/02-experiment-protocol/' | relative_url }}">Experimental method</a></div></div>
<div class="glossary-term" id="ood"><h3>OOD / out-of-distribution</h3><p>Evaluation on cases that systematically differ from training, such as longer distances, larger grids, deeper relation chains, or larger hierarchy depths.</p><div class="links"><a href="{{ '/research/06-learning-and-training/' | relative_url }}">Learning and training</a></div></div>
</div>
