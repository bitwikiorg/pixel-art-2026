# Glossary

A compact bridge between the site's technical language and standard machine-learning terminology. Links favor primary papers, Distill, Scholarpedia, and then Wikipedia for broad background.

<div class="glossary-grid">
<div class="glossary-term" id="cell-state"><h3>Cell state</h3><p>The vector of numerical values stored at one grid location at one moment. In MPF it is the basic computational state, not merely RGB color.</p><div class="links"><a href="https://distill.pub/2020/growing-ca/">Distill: NCA</a><a href="https://en.wikipedia.org/wiki/State_(computer_science)">Wikipedia: state</a></div></div>
<div class="glossary-term" id="embedding"><h3>Embedding</h3><p>A learned numerical representation in which objects or concepts are represented as vectors. Similarity is often reflected by distance or direction in the representation space.</p><div class="links"><a href="https://en.wikipedia.org/wiki/Embedding">Wikipedia</a></div></div>
<div class="glossary-term" id="latent"><h3>Latent representation</h3><p>An internal representation learned by a model rather than a directly observed variable. MPF cell values are latent unless particular channels are explicitly supervised.</p><div class="links"><a href="https://en.wikipedia.org/wiki/Latent_variable">Wikipedia: latent variable</a></div></div>
<div class="glossary-term" id="tensor"><h3>Tensor</h3><p>In deep-learning practice, a multidimensional array. An MPF implementation can simply be a tensor shaped batch × height × width × channels.</p><div class="links"><a href="https://en.wikipedia.org/wiki/Tensor">Wikipedia</a></div></div>
<div class="glossary-term" id="ca"><h3>Cellular automaton (CA)</h3><p>A grid of cells updated from local neighborhood rules. Classical CA rules are typically fixed; neural cellular automata make the rule differentiable and learnable.</p><div class="links"><a href="https://www.scholarpedia.org/article/Cellular_automata">Scholarpedia</a></div></div>
<div class="glossary-term" id="nca"><h3>Neural Cellular Automaton (NCA)</h3><p>A differentiable CA whose cells usually contain vectors and whose local update rule is a neural network trained by gradient descent.</p><div class="links"><a href="https://distill.pub/2020/growing-ca/">Growing NCA</a><a href="https://distill.pub/2020/selforg/mnist/">Self-classifying NCA</a></div></div>
<div class="glossary-term" id="recurrence"><h3>Recurrence</h3><p>Reusing state through time: the next state depends on the current state. Repeating a shared field update is a recurrent computation.</p><div class="links"><a href="https://www.scholarpedia.org/article/Recurrent_neural_networks">Scholarpedia</a><a href="https://en.wikipedia.org/wiki/Recurrent_neural_network">Wikipedia</a></div></div>
<div class="glossary-term" id="convolution"><h3>Convolution / local kernel</h3><p>A weight-shared operation that combines information from a local neighborhood. A 3×3 convolution is a natural learnable local-perception rule on a 2D field.</p><div class="links"><a href="https://en.wikipedia.org/wiki/Convolutional_neural_network">Wikipedia: CNN</a></div></div>
<div class="glossary-term" id="message-passing"><h3>Message passing</h3><p>A view of computation in which nodes repeatedly aggregate information from connected neighbors and update their own states. A grid field is a regular graph.</p><div class="links"><a href="https://distill.pub/2021/gnn-intro/">Distill: GNNs</a></div></div>
<div class="glossary-term" id="inductive-bias"><h3>Inductive bias</h3><p>An architectural preference that makes some solutions easier for a model to learn. Locality and persistent 2D position are possible inductive biases of MPF.</p><div class="links"><a href="https://en.wikipedia.org/wiki/Inductive_bias">Wikipedia</a></div></div>
<div class="glossary-term" id="topology"><h3>Topology / neighborhood structure</h3><p>Which locations are treated as neighbors and how connectivity is preserved. In this project, “topology” usually means the stable spatial/graph organization of cells, not topology in its full mathematical sense.</p><div class="links"><a href="https://en.wikipedia.org/wiki/Grid_graph">Wikipedia: grid graph</a></div></div>
<div class="glossary-term" id="som"><h3>Self-Organizing Map (SOM)</h3><p>A classic method that places learned prototypes on an ordered, usually 2D, grid so nearby nodes tend to represent nearby parts of a high-dimensional data distribution.</p><div class="links"><a href="https://www.scholarpedia.org/article/Kohonen_network">Scholarpedia</a></div></div>
<div class="glossary-term" id="vq"><h3>Vector quantization (VQ)</h3><p>Representing a vector by the index of a nearby codebook vector. VQ-VAE showed how discrete learned latent codes can be trained inside neural models.</p><div class="links"><a href="https://arxiv.org/abs/1711.00937">VQ-VAE paper</a><a href="https://en.wikipedia.org/wiki/Vector_quantization">Wikipedia</a></div></div>
<div class="glossary-term" id="hyperbolic"><h3>Hyperbolic geometry</h3><p>A negatively curved geometry. It is not an extra dimension. Hyperbolic embeddings are useful to study because tree-like hierarchies can sometimes be represented efficiently in such spaces.</p><div class="links"><a href="https://arxiv.org/abs/1705.08039">Poincaré embeddings</a><a href="https://en.wikipedia.org/wiki/Hyperbolic_geometry">Wikipedia</a></div></div>
<div class="glossary-term" id="vsa"><h3>Vector-Symbolic Architecture / HDC</h3><p>Methods that encode structured information in high-dimensional vectors and use algebraic operations such as binding and superposition for composition and retrieval.</p><div class="links"><a href="https://arxiv.org/abs/2111.06077">HDC/VSA survey</a><a href="https://en.wikipedia.org/wiki/Hyperdimensional_computing">Wikipedia: HDC</a></div></div>
<div class="glossary-term" id="attractor"><h3>Attractor</h3><p>A state or set of states that a dynamical system tends to approach. Persistent recurrent fields may learn attractor-like behavior, especially for memory or self-repair.</p><div class="links"><a href="https://www.scholarpedia.org/article/Attractor_network">Scholarpedia</a></div></div>
<div class="glossary-term" id="rate-utility"><h3>Rate–utility</h3><p>A practical compression view: how many stored bits are required to preserve a chosen amount of useful task performance. This is stricter than saying a representation “looks compact.”</p><div class="links"><a href="https://en.wikipedia.org/wiki/Rate%E2%80%93distortion_theory">Wikipedia: rate–distortion</a></div></div>
<div class="glossary-term" id="ablation"><h3>Ablation</h3><p>A controlled change that removes or alters one mechanism to learn what that mechanism contributes—for example, shuffling cell locations while leaving state size unchanged.</p><div class="links"><a href="https://en.wikipedia.org/wiki/Ablation_(artificial_intelligence)">Wikipedia</a></div></div>
<div class="glossary-term" id="ood"><h3>OOD / out-of-distribution generalization</h3><p>Performance on cases that systematically differ from training—for example, longer relation distances than the model saw while learning.</p><div class="links"><a href="https://en.wikipedia.org/wiki/Out-of-distribution_detection">Wikipedia</a></div></div>
</div>
