# Glossary

A compact bridge between the site's technical language and standard machine-learning terminology. Links favor primary papers, Distill, Scholarpedia, and then Wikipedia for broad background.

<div class="glossary-grid">
<div class="glossary-term" id="computational-pixel"><h3>Computational pixel</h3><p>A spatial address whose internal computational object is not restricted to visible color channels. In this lab it may be interpreted as a scalar, vector, tensor, neural unit, token set, memory object or subfield.</p><div class="links"><a href="{{ '/learn/' | relative_url }}">Start Here</a></div></div>
<div class="glossary-term" id="cell-state"><h3>Cell / pixel state</h3><p>The complete numerical state associated with one spatial address at one moment. Depending on the experiment this may be a scalar, vector, tensor, token set, memory state or nested field.</p><div class="links"><a href="https://distill.pub/2020/growing-ca/">Distill: NCA</a><a href="https://en.wikipedia.org/wiki/State_(computer_science)">Wikipedia: state</a></div></div>
<div class="glossary-term" id="projection"><h3>Projection / visualization</h3><p>A lower-dimensional view of a richer internal state. Mapping the first three hidden dimensions to RGB can make a field visible without implying that RGB contains the complete computational state.</p><div class="links"><a href="https://en.wikipedia.org/wiki/Dimensionality_reduction">Wikipedia: dimensionality reduction</a></div></div>
<div class="glossary-term" id="embedding"><h3>Embedding</h3><p>A learned numerical representation in which objects or concepts are represented as vectors. Similarity is often reflected by distance or direction in the representation space.</p><div class="links"><a href="https://en.wikipedia.org/wiki/Embedding">Wikipedia</a></div></div>
<div class="glossary-term" id="latent"><h3>Latent representation</h3><p>An internal representation learned by a model rather than a directly observed variable. A computational pixel can contain latent state even when only a small projection is visible.</p><div class="links"><a href="https://en.wikipedia.org/wiki/Latent_variable">Wikipedia: latent variable</a></div></div>
<div class="glossary-term" id="tensor"><h3>Tensor</h3><p>In deep-learning practice, a multidimensional array. A whole field can be a tensor, and one pixel can itself be interpreted as a smaller tensor with internal axes.</p><div class="links"><a href="https://en.wikipedia.org/wiki/Tensor">Wikipedia</a></div></div>
<div class="glossary-term" id="tensor-pixel"><h3>Tensor pixel</h3><p>A pixel whose internal state is structured as a tensor rather than one flat vector. For example, one address may contain a 4×4 latent matrix. It should be compared with an equal-scalar-count vector using operations that respect the tensor structure.</p><div class="links"><a href="{{ '/research/02-experiment-protocol/' | relative_url }}">Experiment program</a></div></div>
<div class="glossary-term" id="micro-transformer"><h3>Micro-transformer pixel</h3><p>A pixel containing several internal latent tokens processed by a small shared attention block. Attention occurs inside the pixel, which is different from treating the outer pixels themselves as Transformer tokens.</p><div class="links"><a href="https://arxiv.org/abs/1706.03762">Attention Is All You Need</a><a href="{{ '/experiment/#pixelUniverseLab' | relative_url }}">Live mechanism</a></div></div>
<div class="glossary-term" id="subfield"><h3>Subfield pixel</h3><p>A pixel interpreted as a smaller field. An outer grid can therefore become a field of fields, with computation occurring both inside each subfield and between outer addresses.</p><div class="links"><a href="{{ '/research/03-concepts-to-explore/' | relative_url }}">Recursive concepts</a></div></div>
<div class="glossary-term" id="memory-object"><h3>Memory object</h3><p>A pixel or field whose state contains components designed to persist, such as fast activity plus slower memory. A real memory experiment must test retention after the original input is removed.</p><div class="links"><a href="https://arxiv.org/abs/1702.08360">Neural Map</a></div></div>
<div class="glossary-term" id="ca"><h3>Cellular automaton (CA)</h3><p>A grid of cells updated from local neighborhood rules. Classical CA rules are typically fixed; neural cellular automata make the rule differentiable and learnable.</p><div class="links"><a href="https://www.scholarpedia.org/article/Cellular_automata">Scholarpedia</a></div></div>
<div class="glossary-term" id="nca"><h3>Neural Cellular Automaton (NCA)</h3><p>A differentiable CA whose cells usually contain vectors and whose local update rule is a neural network trained by gradient descent. It is the closest structural precedent for the current learned vector-field baseline.</p><div class="links"><a href="https://distill.pub/2020/growing-ca/">Growing NCA</a><a href="https://distill.pub/2020/selforg/mnist/">Self-classifying NCA</a></div></div>
<div class="glossary-term" id="recurrence"><h3>Recurrence</h3><p>Reusing state through time: the next state depends on the current state. Repeating a shared field update is one form of recurrent computation. Recurrence is an experimental axis in MPF, not its definition.</p><div class="links"><a href="https://www.scholarpedia.org/article/Recurrent_neural_networks">Scholarpedia</a><a href="https://en.wikipedia.org/wiki/Recurrent_neural_network">Wikipedia</a></div></div>
<div class="glossary-term" id="attention"><h3>Attention</h3><p>A mechanism that computes weighted interactions between representations. In this project attention can occur inside one pixel, between pixels, between regions or between entire fields.</p><div class="links"><a href="https://arxiv.org/abs/1706.03762">Transformer paper</a></div></div>
<div class="glossary-term" id="convolution"><h3>Convolution / local kernel</h3><p>A weight-shared operation that combines information from a local neighborhood. A 3×3 convolution is one natural learnable communication rule on a 2D field.</p><div class="links"><a href="https://en.wikipedia.org/wiki/Convolutional_neural_network">Wikipedia: CNN</a></div></div>
<div class="glossary-term" id="message-passing"><h3>Message passing</h3><p>A view of computation in which nodes repeatedly aggregate information from connected neighbors and update their own states. A grid field is a regular graph, but the project can also test learned or non-grid connectivity.</p><div class="links"><a href="https://distill.pub/2021/gnn-intro/">Distill: GNNs</a></div></div>
<div class="glossary-term" id="inductive-bias"><h3>Inductive bias</h3><p>An architectural preference that makes some solutions easier for a model to learn. Examples here include locality, stable position, tensor factorization, weight sharing, hierarchy or internal attention.</p><div class="links"><a href="https://en.wikipedia.org/wiki/Inductive_bias">Wikipedia</a></div></div>
<div class="glossary-term" id="topology"><h3>Topology / neighborhood structure</h3><p>Which locations are treated as neighbors and how connectivity is preserved. In this project, “topology” usually means the stable spatial/graph organization of computational pixels, not topology in its full mathematical sense.</p><div class="links"><a href="https://en.wikipedia.org/wiki/Grid_graph">Wikipedia: grid graph</a></div></div>
<div class="glossary-term" id="som"><h3>Self-Organizing Map (SOM)</h3><p>A classic method that places learned prototypes on an ordered, usually 2D, grid so nearby nodes tend to represent nearby parts of a high-dimensional data distribution.</p><div class="links"><a href="https://www.scholarpedia.org/article/Kohonen_network">Scholarpedia</a></div></div>
<div class="glossary-term" id="vq"><h3>Vector quantization (VQ)</h3><p>Representing a vector by the index of a nearby codebook vector. VQ and product VQ are relevant when persistent pixel or field state must be stored compactly.</p><div class="links"><a href="https://arxiv.org/abs/1711.00937">VQ-VAE paper</a><a href="https://en.wikipedia.org/wiki/Vector_quantization">Wikipedia</a></div></div>
<div class="glossary-term" id="hyperdimensional"><h3>Hyperdimensional representation</h3><p>A very high-dimensional distributed representation. “Hyperdimensional” concerns dimensionality; it does not mean hyperbolic geometry or an extra physical dimension.</p><div class="links"><a href="https://en.wikipedia.org/wiki/Hyperdimensional_computing">Wikipedia: HDC</a></div></div>
<div class="glossary-term" id="hyperbolic"><h3>Hyperbolic geometry</h3><p>A negatively curved geometry. It is not an extra dimension. Hyperbolic embeddings are useful to study because tree-like hierarchies can sometimes be represented efficiently in such spaces.</p><div class="links"><a href="https://arxiv.org/abs/1705.08039">Poincaré embeddings</a><a href="https://en.wikipedia.org/wiki/Hyperbolic_geometry">Wikipedia</a></div></div>
<div class="glossary-term" id="vsa"><h3>Vector-Symbolic Architecture / HDC</h3><p>Methods that encode structured information in high-dimensional vectors and use algebraic operations such as binding and superposition for composition and retrieval.</p><div class="links"><a href="https://arxiv.org/abs/2111.06077">HDC/VSA survey</a><a href="https://en.wikipedia.org/wiki/Hyperdimensional_computing">Wikipedia: HDC</a></div></div>
<div class="glossary-term" id="multiresolution"><h3>Multiresolution / recursive field</h3><p>A representation that operates at several scales such as cell, region and field. “Recursive” becomes stronger when the same kind of computational object or update rule is reused across scales.</p><div class="links"><a href="{{ '/research/03-concepts-to-explore/' | relative_url }}">Concepts</a></div></div>
<div class="glossary-term" id="semantic-album"><h3>Semantic Album</h3><p>A collection of persistent fields treated as higher-order objects that may be retrieved, compared, modified or consolidated. It extends the hierarchy from pixel → region → field to field → album.</p><div class="links"><a href="{{ '/research/02-experiment-protocol/' | relative_url }}">Experiment 18</a></div></div>
<div class="glossary-term" id="attractor"><h3>Attractor</h3><p>A state or set of states that a dynamical system tends to approach. Recurrent pixel or field systems may learn attractor-like behavior for memory or self-repair.</p><div class="links"><a href="https://www.scholarpedia.org/article/Attractor_network">Scholarpedia</a></div></div>
<div class="glossary-term" id="rate-utility"><h3>Rate–utility</h3><p>A practical compression view: how many stored bits are required to preserve a chosen amount of useful task performance. This is stricter than saying a representation “looks compact.”</p><div class="links"><a href="https://en.wikipedia.org/wiki/Rate%E2%80%93distortion_theory">Wikipedia: rate–distortion</a></div></div>
<div class="glossary-term" id="ablation"><h3>Ablation</h3><p>A controlled change that removes or alters one mechanism to learn what it contributes—for example, flattening tensor pixels or shuffling spatial locations while keeping other resources similar.</p><div class="links"><a href="https://en.wikipedia.org/wiki/Ablation_(artificial_intelligence)">Wikipedia</a></div></div>
<div class="glossary-term" id="ood"><h3>OOD / out-of-distribution generalization</h3><p>Performance on cases that systematically differ from training—for example, longer relation distances, larger fields or deeper recursive structures than the model saw while learning.</p><div class="links"><a href="https://en.wikipedia.org/wiki/Out-of-distribution_detection">Wikipedia</a></div></div>
</div>
