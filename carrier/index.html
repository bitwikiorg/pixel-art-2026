Exact recovery requires Hamming distance zero." technical: | For a binary field `B ∈ {0,1}^{16×16}`, row-major serialization gives a vector `b ∈ {0,1}^{256}`. Packing maps each consecutive group of eight bits to one byte, so the raw payload is exactly `256 / 8 = 32` bytes. The displayed entropy is the empirical binary entropy `H(p) = -p log2 p - (1-p) log2(1-p)`, where `p` is the fraction of one-bits. It measures symbol balance in one bitmap; it is not a spatial compressor. CRC-32 is used as a deterministic integrity checksum.
