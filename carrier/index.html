Pixel Photon primitive · exact binary ground truth

One pixel. One bit. Then choose what it means.

This lab starts below the neural-network layer. A 16×16 black-and-white image is exactly 256 source bits. The same bits can be read as an image, packed bytes, hexadecimal, harmless text, a noisy communication channel, an associative-memory state, a motif dictionary, a hyperdimensional representation, or a sound signal.

Pixel Photon rule: pixel = address + carrier state + interpretation. The visible black/white bit is the ground truth carrier here. Richer interpretations may create derived state and computation, but they do not create free information.

04 · corruption channel
Noise makes information theory visible.
The raw 256-bit carrier is compared with Hamming(7,4), which expands every 4 source bits to 7 transmitted bits and can correct one flipped bit per codeword.

05 · associative memory
The same bitmap can become an attractor state.
Store up to four 16×16 patterns in a classical bipolar Hopfield memory, damage the current bitmap, and iterate the symmetric network toward a stored pattern.

    
No patterns stored yet.
Extra state: the associative memory allocates a 256×256 floating-point weight matrix. This is not compression; it is a different computational interpretation of the field.

  


  

    
06 · visual motif codec
Repeated local structure can become a dictionary.
Partition the bitmap into 64 non-overlapping 2×2 tiles. Store each unique 4-bit motif once and encode the field as motif IDs. The browser counts dictionary bits and index bits explicitly.

    
Run on a frame or checker pattern to see when a tiny dictionary helps—and run on random noise to see it fail.

  


  

    
07 · hyperdimensional interpretation
Bind address and value into a distributed representation.
Each x coordinate, y coordinate and bit value receives a deterministic 4,096-dimensional bipolar hypervector. The field bundles all 256 coordinate/value bindings into one distributed state, then attempts to query a selected address.

    

      

      
This is a VSA/HDC-style mechanics experiment. A wrong query is informative: distributed bundling has finite capacity and crosstalk.
Extra state: 4,096 logical bipolar dimensions. The browser stores them as signed bytes. This is representation expansion, not free information.

    

  


  

    
08 · cross-domain interpretation
The bitstream can become sound.
Binary frequency-shift keying maps 0 → 440 Hz and 1 → 880 Hz for 10 ms per bit. The purpose is to make “same information, different representation” audible.
