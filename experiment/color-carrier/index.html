Total palette and index bits are counted explicitly." technical: | **Stored RGB state.** RGB888 stores three integers `R,G,B ∈ {0,…,255}`. A directly stored pixel therefore has `8 + 8 + 8 = 24` raw bits and `2^24 = 16,777,216` possible codewords. Hexadecimal and uint24 are exact serializations of the same 24-bit word. **sRGB transfer function.** Colorimetric calculations first convert each encoded sRGB channel `c` in `[0,1]` to linear-light `c_lin`. For `c ≤ 0.04045`, `c_lin = c / 12.92`; otherwise `c_lin = ((c + 0.055) / 1.055)^2.4`. Linear RGB is not three new independent values; it is a deterministic transform of the stored RGB codeword. **XYZ under D65.** Linear sRGB is multiplied by the standard sRGB-to-CIE-XYZ matrix. The implementation uses the D65 reference white `(X_n,Y_n,Z_n) = (0.95047,1,1.08883)`. CIELAB is then computed from normalized XYZ using the standard piecewise cube-root function. The declared sRGB encoding and D65 white point are shared interpretation assumptions. **OKLab and OKLCH.** Linear sRGB is transformed to LMS-like coordinates, cube-rooted, and linearly recombined into OKLab `(L,a,b)`. OKLCH is a cylindrical re-expression with `C = sqrt(a²+b²)` and hue angle `h = atan2(b,a)`. The cylindrical coordinates contain no extra source information beyond their Cartesian parent representation. **Relational quantities.** `ΔE76` is Euclidean distance in CIELAB. The OKLab distance shown is Euclidean distance in OKLab. Relative luminance is computed from linear-light sRGB using the normalized coefficients `0.2126`, `0.7152`, and `0.0722`. Contrast ratio is `(L_high + 0.05)/(L_low + 0.05)`. These values depend on two colors or declared encoding conventions; they are not independently stored inside color A. **Indexed-color accounting.** Four palette entries require `log2(4) = 2` bits per pixel index. If the palette is stored independently as four RGB888 values, palette cost is `4 × 24 = 96` bits. For `N` pixels, the simple exact ledger is `B_indexed = 2N + 96` versus `B_direct = 24N`. Indexed color is smaller only when all pixels are representable by that four-color palette and the saved per-pixel state outweighs palette overhead. A universal, reused, or deterministically derived palette changes the side-information ledger. **Assigned computational meanings.** The uint24 codeword can be mapped to a class, token ID, normalized scalar, memory address, checksum fragment, or other semantic object. Such a mapping is an interpretation. If the mapping rule is shared, it adds no instance bits; if the rule or lookup table varies per instance, that metadata must be counted. **What RGB does not determine.** RGB tristimulus values do not uniquely specify the physical spectrum that produced them. A unique wavelength, spectral power distribution, polarization state, coherence, material reflectance, transmittance, fluorescence, or illumination geometry requires additional state or measurement. scripts: - /assets/js/color-carrier.js ---
