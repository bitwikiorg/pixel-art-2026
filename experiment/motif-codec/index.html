Each raw tile costs four bits. If the dictionary contains `K` motifs, tile indices require `ceil(log2 K)` bits each, while the dictionary itself stores `4K` motif bits plus the metadata needed to interpret the stream. Repetition can therefore reduce description length when `K` is small enough. A checkerboard uses very few motif types; a random bitmap tends to use many and may expand once dictionary overhead is included. This is a fixed exact codec, not a learned compressor.
