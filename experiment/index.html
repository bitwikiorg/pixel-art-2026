Watch a field compute.

This page contains two related experiments. The first is an actual trainable neural network: a shared local neural rule learns to solve a small spatial-relation problem by repeatedly updating a grid of hidden cell states. The second is a hand-designed dynamics sandbox for exploring locality, memory, hierarchy, perturbation, and visualization.

Plain English: instead of one big network looking at everything at once, many small cells repeatedly talk to nearby cells. Training changes the rule each cell uses. The experiment asks whether useful global information can emerge from those repeated local conversations.

Training examples place a white cell A and a yellow cell B on the same row or column. The network learns the answer to: Where is B relative to A?

What is actually learned?

The learnable parameters are convolutional filters and a small readout. The same local filters are reused at every cell and every recurrent step. Gradient descent adjusts those weights from examples.

Training log

This model begins with random weights. Train it, then inspect new examples.
What to notice: recurrence enlarges the effective communication range. With a local 3×3 rule, one update only moves information roughly one cell. Repeating the same rule lets information travel farther without adding a new set of weights at every step.
Architecture grounding

How the trainable model works.

The trainable demo is a small recurrent convolutional network with weight sharing. In Neural Cellular Automata terminology, each grid location holds a vector-valued cell state and a learned local update rule is applied repeatedly. Distill describes essentially the same computational family as a recurrent residual convolutional network with per-pixel updates.

Growing Neural Cellular Automata · Self-classifying MNIST Digits · TensorFlow.js training guide

This sandbox is intentionally different from the neural demo. Its update equation is hand-designed rather than learned. That makes it useful for building intuition about field dynamics, but it should not be confused with a trained neural model.

Interpretation

Coherence asks whether neighboring projected states look similar. Energy summarizes state magnitude. Occupancy measures average absolute activation. Stability measures how much the field-level energy changed since the prior step.
