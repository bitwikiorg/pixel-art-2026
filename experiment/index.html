Protocol

  1. Reset. Keep hierarchy on and shuffle off.
  2. Run 50–100 steps. Export JSON.
  3. Reset. Turn shuffle on. Keep every other setting identical.
  4. Run the same number of steps. Export JSON.
  5. Compare coherence and stability. Do not interpret a difference as proof; use it to specify the real trained ablation.
