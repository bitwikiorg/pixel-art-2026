A seeded random generator makes individual trials reproducible." - label: "Decode and score" text: "Decode the coded branch, compare both recovered fields with the original 256 bits, and report residual errors across repeated trials." technical: | Hamming(7,4) is a linear block code with code rate `4/7`. For 256 source bits, `256 / 4 = 64` codewords are required, so the coded transmission contains `64 × 7 = 448` bits. A standard Hamming decoder uses parity checks to form a syndrome identifying a single corrupted position within each seven-bit codeword. One flipped bit in a codeword can therefore be corrected exactly. Two or more flipped bits in the same codeword exceed that guarantee and may produce an incorrect correction. The raw and coded branches do not use equal transmitted rate. The 192 extra transmitted bits are the redundancy responsible for the error-correcting capability.
