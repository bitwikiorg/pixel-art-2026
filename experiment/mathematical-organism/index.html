Bytes `0–11` parameterize visible morphology and palette. Bytes `12–23` parameterize a two-state recurrent modulator. The 64×64 rendered field contains `4,096` spatial addresses but is recomputed rather than stored as inherited raster data. **Boundary equation.** For normalized coordinates `(x,y)`, the renderer computes `r = sqrt(x²+y²)` and `θ = atan2(y,x)`. The body boundary is a radial harmonic mixture of the form `R(θ,t,h) = b + a₁ sin(k₁θ + φ₁) + a₂ sin(k₂θ - φ₂)`, with small spatial warps applied before the polar conversion. Genome-derived coefficients determine `b`, amplitudes, frequencies, phase rates, and warp strength. **Recurrent modulation.** The transient state `h = [h₀,h₁]` updates as `h(t+1) = tanh(W_h h(t) + W_x [sin(t), cos(t)] + b)`. Genome nibbles map deterministically to signed weights. The two state values modulate boundary amplitude, phase, and spatial warp. The weights are inherited; the hidden state is not. **Interior field.** Pixels inside the generated boundary receive one of several genome-derived colors according to a second harmonic expression over radius, angle, and time. Edge pixels are separately emphasized from the signed distance to the boundary. The RGB palette is derived from genome bytes and therefore is not independent per-frame source information. **Mutation.** The mutation control flips exactly one to three unique bits in the 192-bit genome. The displayed Hamming distance is therefore exactly the inherited edit size, while the phenotype difference can be spatially large because one coefficient influences many pixel addresses. **Determinism boundary.** For a fixed genome, equation mode, time origin, and recurrent reset state, the generated trajectory is deterministic in this browser implementation.
