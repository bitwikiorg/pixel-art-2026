Regeneration discards raster damage and recomputes the phenotype from persistent inherited state." technical: | The visible field contains `24 × 24 = 576` spatial addresses. With four possible palette indices, each address needs `log2(4) = 2` raw index bits, so the complete index raster contains `576 × 2 = 1,152` bits. The four displayed RGB colors are deterministically derived from the already-counted 128-bit genome. They add no independent per-instance palette bits in this implementation. If the palette were stored independently, four RGB888 entries would cost another `4 × 24 = 96` bits. The interpreter contains six morphology grammars: `orb`, `biped`, `quadruped`, `winged`, `crawler`, and `radial`. `genome[0] mod 6` selects the family. Other bytes control dimensions, pattern period and orientation, appendage or limb length, asymmetry, offsets, and palette values. Several bytes participate in more than one expressed property, so the mapping intentionally contains pleiotropy. The apparent `128 / 1,152 = 0.111…` description-to-raster ratio applies only to outputs representable by this fixed decoder. The decoder is shared side information and excludes almost all possible 24×24 four-color rasters. A short genome therefore demonstrates procedural description length inside a restricted family, not general compression. Mutation selects one to three **unique** bit positions and flips each exactly once, so inherited Hamming distance is exactly 1–3 bits. Because family selection uses low bits of byte 0, some small mutations can switch morphology grammar while others alter parameters inside the same grammar. Crossover selects bytes from two parents. Interpolation blends byte values and may cross discrete family boundaries. Raster damage changes generated palette indices without changing genome or derived palette. Regeneration is exact deterministic re-rendering from the persistent description; it is not learned self-repair or developmental regeneration. scripts: - /assets/js/pixel-genome.js ---
GENOTYPE → MORPHOLOGY GRAMMAR → INDEXED PIXELS

One genome can now select different kinds of generated body structure

The decoder contains six finite shape grammars rather than one universal body template. Different seeds can therefore produce orb, biped, quadruped, winged, crawler, or radial forms. Outputs inside each family still share a strong prior because the rules are intentionally transparent and hand-written.
