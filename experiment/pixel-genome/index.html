Damage alters only color indices. Regeneration discards raster damage and renders again from the persistent description." technical: | The visible field contains `24 × 24 = 576` spatial addresses. With four possible palette indices, each address needs `log2(4) = 2` raw index bits, so the full index raster contains `576 × 2 = 1,152` bits. The four displayed RGB colors are deterministically derived from the already-counted 128-bit genome. They therefore add no new independent instance information in this generator. If a palette were instead stored independently with the raster, four RGB888 entries would cost another `4 × 24 = 96` bits. The apparent `128 / 1,152` description-to-raster ratio is meaningful only inside the restricted family defined by the shared interpreter. Many possible 24×24 four-color rasters cannot be represented by this 128-bit family at all. Similar-looking outputs are therefore expected: the decoder intentionally supplies a strong shape prior. Genome bytes have fixed roles. Bytes 0–2 control body position and radii; 3–9 control pattern spacing, eye placement, horn length, leg length, pattern mode, and asymmetry while some also participate in palette derivation; 10–12 control body color and pattern offsets; 13–15 control the dark background color. Because several bytes affect more than one expressed trait, a one-bit mutation can have pleiotropic visual effects. Mutation flips a small deterministic set of genome bits. Crossover selects bytes from two parent genomes. Interpolation blends byte values. GENERATIVE FAMILY · INTENTIONALLY NARROW

Why different genomes still look like the same kind of creature

Every 128-bit genome is interpreted by the same body grammar: one central body, paired eyes, optional horn/leg extent, one of several simple patterns, possible asymmetry, and a four-color palette. The experiment measures variation within that family. It cannot generate an arbitrary 24×24 sprite.
