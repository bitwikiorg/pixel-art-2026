What if a neural network had a place to think?

Pixel Neural Net Lab explores a simple architectural idea: give a neural system a persistent two-dimensional workspace. Every cell in that workspace contains a learned vector state, nearby cells exchange information, and the field changes repeatedly as the network computes.

The object we are studying

A pixel is an address, not a color.

In this project, “pixel” means one location in a grid. Instead of storing only red, green and blue values, that location can hold dozens of learned numbers: a cell state. The visible color is only a way for a human to look at a few of those dimensions.

This makes the field closer to a recurrent neural network laid out over space than to an ordinary image.

Make the mechanism visible.

The browser lab contains both a trainable neural model and a hand-designed dynamics sandbox. They are intentionally separated so learned behavior is not confused with a visualization.

NEURAL NETWORK

Train a local recurrent field

A small TensorFlow.js network learns a spatial-relation task. Every cell uses the same learned convolutional update rule, applied repeatedly over a 12×12 hidden field. Inspect the hidden state after each recurrent step and compare normal versus shuffled state.

The project sits where several established areas meet. Understanding the neighbors prevents us from reinventing existing work and shows which combinations are actually worth testing.

Neural Map shows that a learned two-dimensional memory can remain persistent across time. MPF asks what happens when the memory itself becomes an active recurrent computation.
