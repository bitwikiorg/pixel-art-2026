What if a pixel were a computational universe?

Pixel Neural Net Lab studies a deliberately broad primitive: a pixel is a spatial address whose internal meaning is not fixed. It can hold a scalar, vector, tensor, neural unit, micro-transformer, memory object, subfield, or a recursively larger structure. The visible color is only one possible projection.

The primitive

The pixel is an address. Its interpretation is open.

A pixel can be interpreted as a scalar, vector, tensor, neural unit, micro-transformer, memory object, subfield, or something recursively larger; the lab compares those interpretations rather than prematurely defining MPF as one recurrent-grid architecture.

The word pixel gives us a stable spatial address and a human-visible projection. It does not dictate how much state or computation exists behind that address.

pixel(i,j) = interpretation(stateᵢⱼ)

stateᵢⱼ ∈ scalar · vector · tensor · network · token set · memory · field · …

visible RGB = projection(stateᵢⱼ)
Interpretation ladder

Increase the internal world, not merely the color channels.

The conceptual dimensionality is open-ended, but every real implementation is finite. The scientific question is not “how many dimensions can we name?” It is which interpretation gives useful representation, computation, memory, compression, robustness or reasoning for a measured resource cost.

scalarone value at an address
vectorlearned multidimensional state
tensorstructured latent axes inside one pixel
neural unitstate plus a nonlinear update

subfielda smaller field inside the address
Carrier analogy

Do not confuse what we see with everything being carried.

A photon can be described by more than perceived brightness: frequency, phase, polarization, momentum and helicity can matter. A computational pixel is not literally a photon, but the analogy is useful—the visible projection need not exhaust the state of the carrier.

Likewise, an RGB square can be the human-facing view of a much richer computational object.

The larger program

Pixels can become systems.

Once the primitive is no longer fixed, the project can ask how useful structures compose: tensor pixels, transformer pixels, learned semantic geography, persistent memory, quantized fields, hyperdimensional state, recursive fields, and albums of interacting fields.

TENSOR

Structured state inside a pixel

Compare a tensor-valued cell with an equal-scalar-count flat vector. Internal factorization may matter even when total storage does not change.

ATTENTION

Transformer inside vs between pixels

One experiment puts several latent tokens inside each pixel. Another treats pixels themselves as tokens. Their computational factorization is fundamentally different.

RECURSION

A field inside a field

Cells can form regions; a visible cell can itself contain a subfield; the same organization may recur across scales or across collections of fields.

MEMORY

Persistent semantic objects

A field can be saved, restored, queried, damaged, repaired, compared or allowed to interact with another field.

GEOMETRY

High-dimensional and hyperbolic state

Dimensionality, topology and geometry are separate choices. The lab can test high-dimensional compositional state and non-Euclidean semantic distance independently.

ALBUM

Fields of fields

The unit of computation can eventually become a whole persistent field. Collections of fields may function as associative memory or higher-order representations.

Research neighborhood

Build on what already exists.

Neural Cellular Automata, recurrent networks, Transformers, external memory, vector quantization, self-organizing maps, vector-symbolic systems and hyperbolic embeddings each cover part of the space. The research question is what happens when these interpretations are compared and composed at a spatial computational primitive.
