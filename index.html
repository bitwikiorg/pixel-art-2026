Representation · memory · computation · compression

One pixel. Many possible computational objects.

A conventional pixel stores a display value at a position. A computational pixel keeps the position but allows the finite object at that address to change: a bit, vector, tensor, distributed code, memory state, token set, neural state, or nested field.

Computational pixel

Address + finite state + interpretation.

The address says where the object lives. The carrier state says what is physically represented. The interpretation determines what that state means and what operations can act on it. Changing the interpretation can change the computation without changing the outer spatial address.

pixel = address + carrier state + interpretation

F[i,j] = O_ij

O_ij ∈ {bit, scalar, vector, tensor, hypervector, token set, memory, neural state, subfield, ...}
Finite ground truth

A 16×16 black-and-white field contains 256 source bits.

Black can represent 0 and white can represent 1. Reading the 256 addresses in row-major order produces a 256-bit stream, which packs into 32 bytes. The bitmap, bit matrix, byte sequence, and hexadecimal string are losslessly related descriptions of the same finite object.

16 × 16

256 binary addresses

Each address contributes exactly one source bit. No hidden dimensions or learned parameters are required.

256 bits

32 packed bytes

Eight adjacent bits form one byte. Exact packing and unpacking give a reference case where information accounting is unambiguous.

same source

Image, data, or computational field

The source bits do not change when their interpretation changes. A visible pattern is one projection of the same addressable information.

Added capability

Every added mechanism has a measurable cost and effect.

Robustness

Redundancy can repair corrupted bits.

Hamming(7,4) expands four source bits to seven transmitted bits. Recovery improves because extra coded bits are carried through the channel.

Representation

A field can be recoded into distributed state.

Coordinate and value bindings can be bundled into a high-dimensional hypervector. Retrieval accuracy and storage grow with dimension; the original source information does not.

Memory

A field can become an attractor state.

A Hopfield memory stores relationships in its weight matrix and can move a corrupted state toward a stored pattern. The weights are part of the memory cost.

Computation

Spatial state can be operated on directly.

Binary neighborhood operators such as dilation and edge detection can run over the same address field on a CPU reference or a WebGPU compute shader.

Learning

Update rules can be optimized from data.

Learned local fields and masked reconstruction models are evaluated on held-out examples. Accuracy measures the trained model under its protocol, not automatic superiority of the pixel representation.

Accounting

More state is not more source information.

A deterministic expansion from 256 source bits to a 4,096-dimensional representation may improve separability, robustness, retrieval, or computation. It does not create 4,096 independent source bits. Storage and computation must include hidden state, metadata, codebooks, shared parameters, and other side information.

system cost = carrier + hidden state + metadata + side information + model cost
Pixel Photon is a computational analogy. Photons can be characterized by properties such as frequency, phase, polarization, momentum, helicity, path, and spatial mode. The analogy is limited to the idea that an observed projection need not exhaust the state used by an information-processing system. Every computational implementation here remains finite.
