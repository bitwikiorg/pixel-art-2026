Representation · memory · computation · compression

A pixel is an address whose state can change type.

Black and white give the smallest visible carrier: one bit per address. Color expands the finite state alphabet. Vectors, tensors, token sets, memory, and other computational objects extend it further. Pixels can also be constructed by shared programs, layers, fields, and dynamics. Each extension has an explicit storage cost, interpretation, and measurable effect.

Carrier progression

Binary establishes the baseline. Color opens a larger state space.

01 · BINARY

Black or white

One address stores one bit: `0` or `1`. Packing, decoding, corruption, and recovery can be tested exactly.

02 · COLOR

Finite color state

RGB888 stores 24 bits per address. Indexed color stores a smaller index plus palette information. Hue, Lab, XYZ, and other coordinates may describe the same color state without adding independent source information. Inspect one color →

03 · COMPUTATIONAL OBJECT

Structured internal state

An address can hold an integer, hash fragment, vector, tensor, token set, memory state, or another finite object when its representation and cost are defined.

State layers

Not every property belongs to the same layer.

Stored digital state

Bits physically carried by the computational representation: RGB channels, alpha, palette indices, integers, vectors, tensors, token IDs, memory values.

Derived coordinates

Values computed from other state: HSL, Lab, LCH, chromaticity, hue angle, luminance-related coordinates, gradients, color differences. They add storage only when explicitly cached or transmitted.

Physical measurements

Spectral power distribution, wavelength content, radiance, irradiance, polarization, reflectance, illumination direction, material response, and other properties of real optical systems.

Assigned semantics

Meanings deliberately encoded into finite state: class, probability, confidence, token ID, relation, hierarchy level, instruction, memory address, uncertainty, hash, or compressed payload.

Color, Light, and Pixel State → separates perceptual, colorimetric, optical, spatial, temporal, material, and computational properties with explicit definitions and accounting.

Encoding a pixel can play a tokenizer-like role.

The parallel is exact only at the mechanism level. A tokenizer performs a finite mapping into tokens or codewords. A raw RGB tuple or floating-point vector is simply stored state unless an explicit encoder or quantizer gives it token-like semantics. A pixel is self-similar to the larger computation only when its internal object actually repeats meaningful structure, such as a micro-network, internal token set, recurrent cell, or recursively reused subfield.

Measured capability

Richer state matters only when it changes a measured outcome.

ROBUSTNESS

Redundancy can repair corruption.

Error correction improves recovery by carrying additional coded state. The extra bits are part of the cost.

MEMORY

Persistent state can support retrieval.

Memory requires successful write, delay or interference, and later query—not merely hidden activation during one forward pass.

COMPUTATION

Spatial relationships can participate causally.

Neighborhoods, regions, direction, scale, and topology become useful only when controlled interventions show that those relationships affect the result.

GENERATION

Programs and fields can construct pixels.

Seeds, symmetry, cellular rules, vector fields, shaders, palettes, layers, and time can generate a raster from smaller persistent state plus a shared decoder. Generative pixel engineering →

LEARNING

Operators can be optimized from data.

Learned fields are compared on held-out tasks with resource controls, repeated seeds, and baselines. More dimensions alone do not establish an advantage.

COMPRESSION

Useful structure can reduce total description cost.

Carrier bits, codebooks, palettes, metadata, model parameters, hidden state, and interpreters must all be counted under a declared accounting rule.

Pixel Photon

Visible color can be only one projection of a richer state.

The photon analogy is limited and physical quantities stay physically defined. Frequency, spectrum, polarization, phase coherence, direction, and radiometric quantities describe optical systems; they are not automatically present in an RGB value. The computational parallel is that a visible pixel may expose only one projection of a larger finite state.
