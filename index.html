One pixel. Many possible universes.

Pixel Neural Net Lab studies a deliberately broad primitive: a pixel is a spatial address plus a carrier state plus an interpretation. It may be a bit, scalar, vector, tensor, neural unit, micro-transformer, memory object, hypervector, subfield, or a recursively larger structure. The visible color is only one possible projection.

The primitive

Pixel = address + carrier + interpretation.

A pixel can be interpreted as a scalar, vector, tensor, neural unit, micro-transformer, memory object, hypervector, subfield, or something recursively larger. The lab compares those interpretations rather than prematurely defining MPF as one recurrent-grid architecture.

The word pixel gives us an address and a human-visible projection. It does not dictate the computational object associated with that address.

carrier bᵢⱼ ∈ {0,1} ← simplest case

stateᵢⱼ = g(bᵢⱼ, address, memory, context, …)

visible pixel = projection(stateᵢⱼ)

interpretation ∈ { bit, vector, tensor, network, attention, memory, field, … }
Ground truth first

Before a pixel becomes a neural universe, make the bit undeniable.

The Binary Pixel Photon Carrier is the new entrance to the lab. A 16×16 black-and-white field is exactly 256 source bits = 32 packed bytes. Carrier analogy

Do not confuse what we see with everything being carried.

A photon can participate in information encoding through physical degrees of freedom such as frequency, phase, polarization, momentum or spatial mode. Pixel Photon is a computational analogy—not a claim that a photon stores arbitrary software state.

Likewise, a black/white or RGB square can be the visible projection of a richer computational object. “Infinite universe” means the type system is open-ended, not that finite hardware contains infinite recoverable information.
