Open computational research program · v0.1

Can space itself become part of a learned reasoning language?

Multidimensional Pixel Fields (MPF) investigate persistent 2D neural workspaces in which every cell contains a learned state vector, spatial topology carries semantic structure, multiscale regions provide abstraction, and reasoning is performed by repeatedly transforming the field.

Core representation

Ft ∈ ℝH×W×D   ·   Ft[i,j] = xij(t)

A “pixel” is only a spatial address. Its actual state can contain dozens or hundreds of learned dimensions. RGB is a visualization of that state—not the storage primitive.

The architecture

Five claims. Each one can fail.

The project is intentionally decomposed into falsifiable components. The important contribution is not “pixels with vectors”; neural cellular automata already establish that. The question is whether persistent topology, learned specialization, multiscale recurrence, and explicit state persistence add measurable computational value.

01 / STATE

Each cell is an embedding

A cell stores a D-dimensional learned state: content, working memory, routing, relation, confidence, or whatever decomposition training discovers.

latent statevector field
02 / TOPOLOGY

Position must matter

If randomizing cell locations does not hurt performance, the “field” is decorative. Persistent addressability is the first causal test.

ablationsemantic geography
03 / DYNAMICS

Reasoning is field evolution

The state is iterated F₀→F₁→…→Fₜ. Intermediate propositions should become decodable and causally relevant over time.

recurrencetest-time compute
04 / SCALE

Regions summarize regions

Cell → region → field → album. “Fractal” is reserved for architectures that genuinely reuse the same rule across scales.

multiresolutionhierarchy
05 / RATE

Compression must count bits

A high-dimensional grid is not intrinsically compressed. Any claim must survive codebook, side-information, model, and serialized-bit accounting.

rate–utilityVQ
06 / PURPOSE

Roles should be causal

A pretty projection is not interpretability. Targeted cell or region interventions must selectively alter the computation they supposedly represent.

mechanisticcausal roles
